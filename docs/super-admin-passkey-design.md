# تصميم بوابة السوبر أدمن الخاصة

ستكون البوابة على مسار مستقل لا يظهر في تنقلات موقع الزبائن، ويمكن تثبيتها من iPhone أو الكمبيوتر كأيقونة مستقلة. تعتمد المصادقة على **Passkey** مرتبط بنطاق `hatfaltmyez.com`؛ ويستخدم المتصفح تشفير المفتاح العام، بينما تبقى البصمة أو Face ID داخل الجهاز ولا تُرسل إلى الخادم.[1] تعمل WebAuthn ضمن اتصال HTTPS آمن، وهو متوفر على الدومين الرسمي.[1]

| العنصر | القرار الأمني |
|---|---|
| التسجيل الأول | رابط تفعيل عشوائي لمرة واحدة، محفوظ كـSHA-256، ينتهي تلقائيًا ويُلغى فور تسجيل أول Passkey |
| التحقق | `userVerification: required` لضمان استخدام بصمة الوجه أو الإصبع أو رمز قفل الجهاز |
| تخزين Passkey | معرّف الاعتماد، المفتاح العام، العداد، نوع الجهاز، حالة النسخ الاحتياطي ووسائط النقل وفق نموذج SimpleWebAuthn[2] |
| جلسة السوبر أدمن | كعكة HttpOnly موقعة، قصيرة المدة، لا تُخزن في localStorage |
| دخول الفرع | إصدار جلسة المالك والفرع بالإصدارات الحالية بعد تحقق Passkey فقط |
| كلمات المرور الحالية | لا تُقرأ ولا تُعرض ولا تُحدّث؛ تظل التجزئات والإصدارات كما هي |
| البوابة المثبتة | Manifest مستقل يبدأ من مسار السوبر أدمن ولا يفتح الصفحة العامة |

تستخدم الواجهة `startRegistration({ optionsJSON })` و`startAuthentication({ optionsJSON })`، ويستخدم الخادم توليد الخيارات والتحقق من الاستجابة عبر SimpleWebAuthn v13.[2] يُحفظ تحدي كل عملية في كعكة موقعة قصيرة العمر، وتخضع إجراءات التسجيل والمصادقة وحدود المحاولات إلى حماية CSRF وRate Limiting الحالية.
