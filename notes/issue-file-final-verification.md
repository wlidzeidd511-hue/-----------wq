# تحقق ملف الملاحظات الشامل

## لوحة المالك

- تمت المعاينة على فرع البساتين بجلسة مؤقتة موقعة دون استخدام أو تغيير كلمة المرور.
- إجراء **إنشاء الفاتورة** ظاهر كأول بطاقة أعلى اللوحة.
- أزرار **إضافة عطل أو زيادة** ظاهرة بجانب كل فاتورة، والتحديد المتعدد وشريط الأرشفة الجماعية ظاهران.
- سجل آخر الرسائل قابل للفتح والإغلاق، وبحث العميل بالهاتف ظاهر.
- بعد أرشفة سبع فواتير اختبارات مؤكدة عبر API المالك، لم تعد تظهر في القائمة النشطة؛ بقيت سبع فواتير حقيقية فقط في المعاينة.
- لم تُحذف أي فاتورة نهائيًا، وسجلات الاختبار المؤرشفة قابلة للاسترجاع من الأرشيف.

بعد ملاحظة المالك الأخيرة، أضيف قسم **فواتير تحتاج متابعة** مباشرة تحت إنشاء الفاتورة وقبل التنبيهات والإحصائيات. أظهرت المعاينة ثلاث فواتير مفتوحة فقط (#125 و#124 و#117)، ومع كل واحدة قائمة تغيير الحالة وزرا العرض والتعديل والعطل أو الزيادة. لم تظهر الفواتير المسلّمة أو الملغاة أو المؤرشفة في هذا القسم، مع بقائها في القائمة العامة والتاريخ حسب صلاحيات المالك.

## بوابة الموظف

تمت المعاينة بجلسة موظف مؤقتة موقعة. ظهر اسم الموظف **وليد** وفرعه المعيّن **فرع البساتين** وصلاحياته الفعلية بوضوح، مع تنبيه أن تغيير الفرع والصلاحيات من اختصاص المالك. ظهر بحث العميل برقم الجوال، وعدّادات طلبات الفرع، وزر الفاتورة الجديدة، ولم تظهر بيانات فرع آخر أو أدوات غير داخلة في صلاحيات الموظف.

## الفاتورة والطباعة

تأكد ظهور الشعار والباركود وQR والحساب والضمان والعبارة الختامية في قالب الطباعة. كشفت محاكاة Chromium أن `size: 80mm auto` غير صالح في CSS ويعيد الورقة إلى Letter، كما أن فاتورة فرع البساتين أظهرت نصًا احتياطيًا بدل ساعات العمل المطلوبة. يلزم تصحيح مقاس الصفحة وتثبيت ساعات العمل 4 عصرًا–12 ليلًا قبل اعتماد التحقق النهائي.
